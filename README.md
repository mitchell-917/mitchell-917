## About

Software engineer in London. I build **algorithmic trading systems** for MetaTrader 5 and TradingView, and **production React + TypeScript applications** with the test coverage to back them up.

- **Right now:** a multi-timeframe Nasdaq-100 expert advisor for MetaTrader 5, designed around prop-firm risk limits, with every default expressed in ATR or R rather than points.
- **How I work:** evidence before intuition. Backtests with frozen parameter sets, out-of-sample validation, Monte Carlo drawdown checks, and a trade journal for every system. In apps: strict TypeScript, real tests, CI on every push.
- **What I enjoy:** turning noisy data into something a person can read at a glance, whether that is a candlestick dashboard or a contribution graph.

<details>
<summary><b>How this page works</b></summary>
<br/>

Everything you see is produced by a zero-dependency Node script, [`scripts/generate.mjs`](scripts/generate.mjs), that runs in GitHub Actions once a day:

1. Pulls public data from the GitHub API: profile, repositories, the contribution calendar (GraphQL, with a public mirror as fallback) and each repository's git tree.
2. Measures languages from the trees themselves, so Pine Script and MQL5 are counted even though GitHub's own language stats ignore them.
3. Writes one JSON snapshot, [`assets/data/profile.json`](assets/data/profile.json), which the interactive lab also loads.
4. Renders every graphic as an SVG in light and dark variants with embedded brand icons, and commits the results.

Content lives in [`profile.config.json`](profile.config.json). Run `npm run build` to refresh locally, or `npm run build:offline` to re-render from the last snapshot.

</details>
